# Dot Files

Configuration files for my Arch Linux (Omarchy) setup, including Hyprland and related tools.

## How to use this on a new machine

### 1. Download your dotfiles

Clone the repository to your home folder.

```bash
git clone [https://github.com/tanishenigma/dots](https://github.com/tanishenigma/dots)
```

### 2. Run the installation script

Enter the directory and execute the script to symlink your configurations.

```bash
cd ~/dots
chmod +x install.sh
./install.sh
```
